# TASG — Home Final Phase Start

Checkpoint before the final Home/boombox refactor.

## Approved direction

- Preserve the current underground alley composition.
- Preserve the real band wordmark and existing social links.
- Strengthen the worn industrial plaque/sign system without filling every surface with plates.
- Keep the red active/provisional accents restrained.
- Treat the boombox as a real object that happens to be the player, not a web player pasted over a boombox.
- Build CD insertion/tray-close interaction before playback.
- Use the supplied CD tray closing sound effect.
- Keep display, play, stop, previous, next and eject integrated into the physical boombox face.
- Maintain true reflow for portrait and landscape layouts; never require user zoom.
- Keep touch targets usable without hover.
- Do not add slogans, ideology text or decorative filler phrases.

## Safety / rollback

The current published Home remains the rollback point. New implementation work should be developed as a coherent block and reviewed before replacing the live direction.
